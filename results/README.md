# Resultados

Esta carpeta contiene resultados derivados y verificables; no incluye el dataset:

- comparación de experimentos;
- historiales por época;
- métricas globales y por clase;
- predicciones finales;
- predicciones utilizadas para construir las matrices de confusión;
- registro de reproducibilidad de la evaluación final.

Las figuras utilizadas en el informe se conservan en `reports/figuras/`. Las ejecuciones temporales, cachés y checkpoints redundantes permanecen fuera del control de versiones mediante `.gitignore`.
