# Modelos

Esta carpeta contiene únicamente el checkpoint final seleccionado antes de abrir el conjunto de prueba y su manifiesto de integridad. Se registran:

- arquitectura y época;
- configuración de entrenamiento;
- clases y orden de salida;
- métricas de validación;
- SHA-256 del archivo.

Los checkpoints intermedios no forman parte de la versión publicable. La arquitectura, la configuración seleccionada, las métricas y las limitaciones se documentan en `docs/MODEL_CARD.md`.
