# Notebooks

`ETID_Actividad_2.ipynb` contiene el pipeline autosuficiente de la Actividad 2 y conserva sus resultados visibles. Fue ejecutado y auditado sin errores ni rutas personales.

El notebook localiza el dataset mediante `ETID_DATA_ROOT` o la ruta relativa `data/raw/ETID`. Las instrucciones de preparación, verificación y ejecución están en `docs/REPRODUCIBILITY.md`.
